# 商品编辑的保存与取消

主按钮显示“保存并返回详情”或“保存当前件”，保留“保存商品”这一稳定可访问操作名，并用 aria-describedby 说明保存去向。取消仍经过原离开保护，读屏说明及确认框明确只放弃未保存资料/未完成图片，已生效图片和经营记录保留。

已保存图片的操作保持原独立事务。取得成功回执后显示具体结果及文字仍需保存；回执确定但重新读取失败，显示仍待读取，不把旧视图冒称最新。未知回执仍核对原尝试；封面/瑕疵/归档权限、原图、权利和审计不变。

扩展原 studio 的图片案例，真实标瑕疵和归档后取消文字，核对数据库中图片结果保留而文字未写入。未新增网络成功模拟；自身固定 head 的完整 CI 待执行，不引用第一片结果代替。
