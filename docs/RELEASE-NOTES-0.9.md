# 0.9.0-rc.1 · 经营者交互收口

本版不增加新的业务模型，重点修复“功能存在，但经营人员需要猜系统怎么想”的交互问题。数据库结构、TM编号、库存、账务、素材权利和审计规则不变。

## 商品录入
品牌改为单一的可搜索选择器：输入品牌名、中英文名或别名即可查找，点击或键盘选择后保存稳定ID。页面不再同时出现一个下拉框和一个搜索框。

成色、颜色、主要材质属于数量有限的标准选项，使用普通下拉框，不伪装成自由搜索输入。品牌可在录货上下文新增；颜色、材质、成色统一到字典管理维护。

已选品牌刷新后保持明确显示。继续输入新品牌时替换旧标签而不是拼接。延迟搜索结果不能覆盖用户已经明确选中的值。输入品牌文字但未真正选中时，保存和筛选都会明确提示。
## 业务语言
商品字段改成经营人员可以直接理解的名称：标签尺码、实测尺寸、尺寸来源、材质成分 / 细节、成色、瑕疵与使用痕迹、实物持有、记录类型、资料状态。旧Excel/CSV表头仍兼容，不修改历史数据键。

准备发布只保留经营动作：选择账号与使用场景、改文案、选图、核对、生成资料。自有实拍不会出现供应商授权表单；选到供应商图片时才要求填写“供应商图片授权依据”。

系统运行页的队列和服务状态改为中文主视图；技术枚举保留在接口和诊断层。设置页角色显示中文，API与后台任务等低频入口收进“技术维护”。成交记录每行只突出“补收支”，退款、合作归属和完好退回放入“更多”。

## 交付边界
本版没有数据库迁移，没有开启真实平台自动发布、支付、联网付费AI或自动结算。`test/browser/ux09.spec.cjs` 与 `ux09-audit.spec.cjs` 必须同时进入 Chromium 和 WebKit；完整结果以本版本 `docs/validation/0.9.0-rc.1/` 为准。
