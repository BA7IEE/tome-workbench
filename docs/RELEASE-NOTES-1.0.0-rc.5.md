# 1.0.0-rc.5 Credit退款成本

现金与Store Credit按同等价值确认采购净额。可填写原现金支付、Credit使用、现金退款、Credit退款四项，按原采购汇率扣减；明确归属的退款只冲减对应商品。支持确认零净支付，不因缺少RMA放过退款核对。修复其他来源关闭Credit支付规则后实际扣款模式仍加回Credit的问题。

汇率在成本依据确认时固定。来源订单或成本规则变化后要求重新核对，不会从新的来源净支付推导旧汇率。新证据保存在既有不可变成本依据修订中，无数据库迁移。已有CostEntry不自动重算；历史Sale.cost保持原值。

验证命令、退出码和真实运行证据由`npm run verify:release`写入`docs/validation/1.0.0-rc.5/summary.json`及verification.log；未生成通过报告前不视为验收完成。

首次全量运行发现旧workbench建档辅助步骤把地址变更误当成保存完成，WebKit提前离开时被保存保护拦截。辅助步骤改为等待“已保存”和按钮恢复，再真实点击“查看详细记录”；未修改保存保护、未刷新页面、未放宽业务断言。

本次未实现自动历史月均汇率、跨页批量成本确认、自留与退回实物的完整特殊分摊、TRR全量采集、图册和商品中心整体改版。真实账户商品尚未导入；测试使用独立tome_test合成数据。
