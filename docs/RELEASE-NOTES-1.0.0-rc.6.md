# 1.0.0-rc.6 导入核对与来源资料

外部Agent或脚本负责采集，中台负责接收、保存、核对和人工确认。新增商品/字段/图片清单核对，缺件、漏传原文件或尺寸不符时拒绝封批；来源无法取得的字段及缩略图明确标记。旧无清单记录继续可用，但显示完整性未核验。

待确认支持跨页选择最多1000件，按100件分段提交，保留版本检查、逐件成功/失败结果和回执丢失恢复。候选图册可直接读取全部原文件；商品编辑器和采购历史复用来源资料入口。后续稀疏采集不清空已有来源参数或覆盖人工建议，已建档商品可继续增加来源证据而不直接修改Item。

无新数据库迁移、无依赖升级、无内置采集器、无真实订单导入或公网部署。来源清单与哈希核对不等于中台独立证明远端网站未漏报或图片确为网站最高分辨率。自动历史汇率与跨订单成本批量确认不属于本次改动。

开发中发现并修复手机图册溢出及商品来源入口藏在折叠区域的问题。最后的完整验证命令、退出码、源码指纹及边界见`docs/VALIDATION.md`与本版本`docs/validation/1.0.0-rc.6/summary.json`；未通过前不得打包。
