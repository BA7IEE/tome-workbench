# 1.0.0-rc.7 导入商品的内部识图

真实订单试用发现：原图已保存并关联到TM，但商品库只读取实拍/细节图，导致来源参考图被显示成“还没有图片”。本版让未归档参考图出现在内部商品封面和图片数量中。参考图仍为内部资料、未核验，图片公开使用和发布审批规则不变。

单件建档或关联已有TM成功后，从跨页选择中移除该候选；保留其他候选的选择，避免已处理完仍显示选中。

自动化延伸现有原图旅程，核对商品库实际加载、图片数和素材权限不变，并增加单件处理后的选择回归。完整验证由`docs/VALIDATION.md`及`docs/validation/1.0.0-rc.7/summary.json`记录，未通过不得打包。

真实采购数据、原图、凭据和逐件验收记录只保存在本机私有data目录，不作为自动化测试数据或发布内容。人民币成本、公开素材授权及实际销售没有因本次内部图文建档自动完成。
