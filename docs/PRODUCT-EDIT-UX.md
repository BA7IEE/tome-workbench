# 商品编辑 UX 第一批 · 云端实施

基线为远端 `main@dfa1de8da4c9ea6d4b5f2ed980206955ebd8db4d`（rc.14），保留 AntD 6.6.5、ProComponents 3.1.15-5 与 React 18.3.1。独立分支为 `fix/product-edit-ux-batch1`。本批仅改商品表示层、已有入口与合成浏览器验收；不新增 API、migration 或依赖。

## 日常操作

商品库表格的固定操作列及图片卡片都直接显示「编辑」。进入与详情「编辑商品」相同的完整编辑页，保留原列表筛选、排序、页码、视图、选择及滚动位置。从列表进入时保存留在本件；取消或「保存并返回」回到原列表。从详情进入时主保存仍返回本件详情。快速修改保留其轻量用途，说明名称、归类、报价、成色的范围，完整编辑入口与草稿转交均保留返回上下文。

图片上传按钮固定在图片区顶部，已保存图册在下方独立滚动（桌面最多 360px、手机 240px），可用键盘聚焦滚动区域。尺寸与材质默认展开，排在商品描述前，手机排在图片后。顶部「定位图片 / 定位尺寸与材质 / 定位报价」按钮直接定位并聚焦对应控件；手机继续使用既有固定保存、取消操作条。

保存中、保存未完成、结果待核对、资料已保存但图片待完成、核对后继续保存与整体已保存分别显示。只有文字、新图片及必要的后续读取全部完成后才显示整体已保存。冲突保留输入及上传文件，显式比较、确认合并后再提交；写入后断线仍按冻结的原请求号核对。

## 现有保存边界

已有图片的设封面、标瑕疵、移除通过媒体命令立即保存；取消编辑只放弃未保存输入及待上传内容，不能撤销已经生效的图片或经营记录。文字 PATCH 带 item version，新图片通过已有上传队列提交；多个 HTTP 请求不是一个原子事务。媒体变更目前不递增 item version。本批将这些事实放在编辑页说明中，保留现有权限、幂等与未知结果恢复。

后续 edit-commit 事务、媒体并发 token、staging/claim/清理、冻结幂等键和未知结果恢复属于独立第二批设计。本批没有实现或宣称具备这些事务保证。

## 验收映射

`test/browser/studio.spec.cjs` 新增三例，纳入既有 Chromium/WebKit 相同套件：

- 1440px 与 390px，各从表格和卡片直接编辑具有 13 张合成图的商品，核对上传位置、图册限高、默认展开、尺寸聚焦、无页面横向溢出；改尺寸/材质、上传、保存、重开，确认原筛选和选择以及取消零资料写入。
- 真实并发 PATCH 触发版本冲突，上传文件与双方不同字段保留；真实写入成功后丢回执、重复点击只发一次、原请求号核对、补完上传后重读真实结果。

旧尺寸测试以前先点击关闭的 summary 才能填写，现在用既有 `revealSection` 仅在折叠时真实点击；不隐藏字段或强制点击。手机旧几何断言要求尺寸位于介绍后，与本批明确前移要求不再相符，改为核对图片后、归类前且默认展开；宽度和无溢出断言保留。快速修改测试同步入口文案，原离开确认、草稿、权限及回执断言保留。其余领域测试与两浏览器配置保留。
