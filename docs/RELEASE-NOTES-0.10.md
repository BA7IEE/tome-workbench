# 0.10.0-rc.1 · 快速录货与快速修改

0.10 的目标不是增加商品字段，而是把高频经营动作从完整工作区中拆出来。商品列表的主按钮改为「快速录货」；完整建档仍在「更多」和货源接手流程中保留。

快速录货只显示图片、名称、品牌、品类、报价、币种、成色和图片来源。尺寸、材质、鉴定、英文、研究资料、发布资料不在首次建档中出现。保存后可以直接录下一件，或进入同一件商品的完整工作区继续完善。

图片支持一次多选、拖入、粘贴、预览和提交前单张移除。上传沿用现有原件、幂等键和来源规则，不建立第二套弱校验上传接口。连续录货会持续显示上一件的TM编号和名称作为确认。

商品列表行尾「更多」新增「快速修改」：仅处理名称、品牌、品类、报价、币种和成色。图片、尺寸、鉴定、库存、发布和财务等仍进入对应完整流程。快速修改使用商品版本号；有人同时修改时不会覆盖，当前输入保留并提示重新读取或进入完整编辑页核对差异。

快速录货打开后自动聚焦商品名称；Ctrl/⌘+Enter 保存并下一件，Ctrl/⌘+Shift+Enter 保存后进入完整资料页。桌面与手机均使用视口内滚动弹层，底部动作固定，不用为最后字段滚过操作按钮。

本版本没有数据库迁移，没有修改商品、库存、财务、授权和发布领域规则。快速入口最终仍调用现有 `/items`、`/items/:id` 与 `/assets/upload` 命令。

`test/browser/ux10.spec.cjs` 是新增双浏览器门禁，覆盖字段暴露范围、连续录货、图片上传/移除、键盘操作、手机布局、保存后完善、快速修改和并发冲突保护。完整商品工作区旧回归继续直接进入完整建档路由，不能用快速入口替代旧业务覆盖。
