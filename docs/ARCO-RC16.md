# 商品工作区 Arco 迁移 · 1.0.0-rc.16

本文件记录 rc.16 迁移时的结构。rc.18 已清理旧样式文件和 legacy 层，当前结构见 [UI-CLEANUP-RC18](UI-CLEANUP-RC18.md)；原有业务边界继续有效。

本轮目标是统一商品库和商品编辑的控件、分区与操作位置。页面以商品图片和维护为中心，不扩大采购、发布或财务范围。验收状态以 docs/VALIDATION.md 和本版完整检查结果为准，不能用组件接入或截图替代业务验收。

## 已改动的展示范围

- 商品库由 React 渲染，使用 Arco 表格、按钮、输入、复选框、标签、空态和下拉菜单。列表与图片视图、筛选、跨页选择、排序与返回位置继续共用原有上下文。
- 勾选后优先显示下载资料、导出清单、逐件编辑；定价、批量属性、交接、暂停、客户选品与删除等按现有权限进入「批量操作」。表格操作列固定在右侧，不要求先横向滚动才能找到；行内菜单使用挂在表格外的 Arco Dropdown，避免被滚动容器裁切。
- 完整商品页的命令区与字段采用 React + Arco。左侧名称、图片、介绍；右侧品牌、品类、价格与成色。尺寸、来源、鉴定与扩展资料保持按需展开，手机按录货顺序重排。
- 快速录货、快速修改共用 React 字段。首次录货仍仅要求名称，不扩张首次采集字段。
- React 18.3.1、ReactDOM 18.3.1、Arco 2.66.16 固定版本。Arco 的 MIT 声明保存在 docs/ARCO-LICENSE.txt。CSS 只引入当前组件及官方声明的依赖；UI 依赖与应用脚本分别构建，便于缓存。

## 代码与数据边界

前端已有的图片队列、品牌异步查询、来源证据、库存、发布、表单命令和资料包对话框继续由原模块管理。它们不是全部改写为 React。本阶段通过显式容器隔离所有权，React 不重新构建这些容器中的文件、请求回执或原始证据。

`web/src/arco/runtime.tsx` 管理 React 根与页面 AbortSignal；字段冲突合并只重建字段根，先保留文件队列、图片与来源容器。筛选字典的生成结果按路由固定，选中商品引起的 React 更新不得清空已经选好的品牌或异步控件状态。

字典规则不变：品牌为可搜索组合框，成色、颜色、主要材质为原生选择控件。来源措辞仍显示为来源参考，不自动升级为我们的标准化或验货结论。Arco 复选框适配器为真实 input 补齐可访问名称和半选状态。

保存继续使用 readProduct、changedProduct、WriteAttempt、ProductUploadQueue；FormData 必须在锁控件之前捕获。保留同一命令键、原图、关闭再开恢复、乐观版本冲突、审批与发布检查。未变更 API、数据库结构、成本政策、库存规则或来源关系。

`ui08.css` 仍是最终样式入口，层序为 legacy / arco-base / workbench / arco / product，由最先加载的 style.css 声明。Arco 的页面重置在业务样式之前，组件样式在业务样式之后，防止全局 h1 等默认样式覆盖手机页面布局。自定义层仅负责业务布局和旧控件适配。不能重新导入被废弃的视觉文件。

## 最小验收与回归

最小操作链：快速录货保存名称和原图 → 商品库找到同一 TM → 修改介绍并保存 → 下载资料中的原图字节与上传一致。

新增 arco-workspace.spec.cjs 覆盖选择与菜单切换保留筛选草稿/品牌，以及并发改价后合并保留中文草稿、主动保存、离开重开无 React 运行错误；纳入 Chromium 和 WebKit。既有 product-library、ux10、studio、operations、字典、交互、媒体授权和业务全套测试继续执行。

旧测试仅在真实入口变化处调整：批量定价/属性先打开「批量操作」；行菜单从原生 details 切换为 Arco Dropdown 后，检查 aria-expanded、页面弹层及真实命中区域。原来的仅在行 DOM 中寻找弹层不再符合门户弹层结构。保留外部点击、Escape 回焦、实际修改/删除、断线与冲突的全部业务断言，不删除或重命名旧用例。

## 本轮未覆盖的改造

导入记录、设置和历史业务页面仍使用原有渲染方式；分享资料包等业务对话框保留现有命令控制器。原图查看、下载与图片权利仍由现有媒体模块负责。没有接入真实采集、第三方发布或公网部署。最终界面是否顺手仍需经营者试用反馈。
