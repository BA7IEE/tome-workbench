# 快速修改草稿转交

基于快速录货第一片后继续实施。原“完整商品页”保持既有明确放弃确认，不改旧回归含义。新增“保留修改并进入完整编辑”，转交账户、商品、旧版本和可编辑字段；不把草稿放入 URL 或自动持久化财务/会话信息。

转交前仍阻止忙碌和未知写入；只有成功捕获草稿后才关闭窗口。完整页读取失败不消耗转交记录；已挂载且具有离开保护后清理。同账户最多保留20件内存转交；换账户清除，不能当跨浏览器或刷新恢复。

只把人工改变的字段与原版本作为比较基线，未改字段采用服务器最新值。原输入（包括未选品牌或非法报价）按文本显示，不用推断代替标准字典选择。版本变更时提供“核对差异”，复用既有合并确认；未勾选不合并，合并后还需显式保存。

新增两项 ux101/ui08 范围内的实际浏览器回归：真实并发 PATCH 后保留草稿且核对前零新写入、未选品牌转交后继续阻断。两项轻量三方比较测试已通过，完整 UI 按自身固定 head 的 CI 验证；第一片 CI 不证明本片，Mac 不运行全套。

显式转交的品牌/成色不再把旧值传给 legacy raw 自动匹配；清空保持清空，未选品牌文本保留并继续阻断。未转交的其他字段仍按原合同读取最新值。强化旧品牌存在时的未选新文本案例，增加真实品牌/成色清空、转交、保存后无字典绑定的案例；没有自动采用新版本或猜标准项。

清空回归进一步定位旧字典控件：清除会重读选项，而已存在 ID 时未消费的 legacy raw 会重新精确匹配旧品牌。人工选择、清空或输入之后即消费 raw（固定下拉的 change 同样处理）；最初旧资料的合法匹配保留，不再覆盖后续明确人工意图。清空案例同时核验快速窗口重读后保持空，再核验转交与数据库清空。
