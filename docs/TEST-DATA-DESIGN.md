# 测试数据隔离与清理

目标：经营者可以完整测试录货、发布回执、成交及退款，然后明确清理测试记录，不被正常账目删除保护卡死。不删除历史金额、原图、审计或已确认快照。

- 新建时可由管理员明确选择测试商品；默认仍是正式商品。测试模式不是根据标题或名称自动推断。
- 正式统计、合作对账和公开展厅默认排除测试商品；测试成交在单独视图可查。
- 旧的模拟商品：管理员打开清理预览，核对关联成交、费用、发布和对账；输入TM编号，声明没有真实收付款/交易及仍在销售的外部商品，再归档。
- 后端验证权限、版本、预览摘要和两项声明。关联记录改变必须重新预览，不接受过期确认。
- 归档保留商品身份及所有财务记录，只改为TEST并移入回收站，取消模拟待办/预留；不调用外部下架或退款。
- 外部平台观察记录原样保留，不伪造实际下架成功。管理员的“无真实发布”声明单独进入审计。
- 涉及已确认对账需额外确认影响；历史快照不改写，显示含隔离测试记录的提示，可建立差额更正快照。
- 回收站恢复只恢复到测试模式和暂停状态，不恢复成正式业务，也不自动上架。普通编辑和导入不得改变模式。
- 未选择的真实商品不受影响。旧记录不会因升级自动分类、清空或退款。

验证：真实数据库中检查归档后行数和历史金额不变、统计隔离、确认快照不变、对账更正、权限和并发；浏览器验证清理入口、取消、预览变化、确认、测试视图和恢复。全部使用tome_test合成数据。
