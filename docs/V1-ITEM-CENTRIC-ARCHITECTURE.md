# ToMeBoutique 商品经营中台 v1.0 · 商品中心架构

## 唯一核心
系统的经营核心是每一件实际商品（TM商品），不是采购订单、货源记录或发布渠道。订单/包裹/RMA/外部商品页均为来源证据；商品一旦生成TM编号，日常维护、询盘、销售、素材、状态都围绕TM进行。

## 四层结构
1. 外部采集接入层：Codex、WorkBuddy等桌面Agent按统一协议提交批次、来源事实和图片；中台不内置爬虫，也不绑定任何Agent品牌。
2. 待确认候选层：Agent数据只进入候选池。系统做去重、品牌/品类标准化建议、成本预计算和异常提示；不得直接创建正式库存。
3. TM商品事实层：人工单件或批量确认后才生成永久TM编号。商品可以资料不完整但处于可售；资料完整度只用于提醒。
4. 销售使用层：渠道文案、发布、询盘、预留、售出、下架任务均引用TM，不反向成为商品事实来源。

## 不变量
- 外部Shipped/Sold/Canceled/RMA永远不是本地库存状态。
- 外部成色永远不是本地成色；可给映射建议但必须保留原值。
- Agent永远不能直接生成TM、改变库存、确认人民币成本或发布商品。
- 同一个外部来源记录重复提交必须幂等；原始快照不可静默丢失。
- 一个TM可关联多个来源证据；来源订单退居历史，不成为日常操作主入口。
- 图片先作为候选素材入库，确认TM后复用原文件生成商品素材记录，不重复下载原件。
