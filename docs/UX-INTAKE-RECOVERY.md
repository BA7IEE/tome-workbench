# 快速录货退出与同一 TM 恢复

本片基于 PR #57 的已验证 AntD/ProComponents 候选 `98df13d`，后续分支 `fix/ux-intake-and-recovery`、draft PR #58。本片只改录货窗口、同一商品的资料保存与图片队列，不改默认库存、权限、编号、来源事实、图片权利或外部发布。没有 merge/deploy 或生产数据操作。

## 退出

货源链接普通点击先调用与关闭按钮相同的 dirty/busy/uncertain 检查。拒绝放弃留在原路由、窗口和原 File；确认允许后才关闭并导航。提交中不离开；修饰键打开新页不关闭当前草稿。现有 `form` 的 void 回调合同保留，只有需导航的表单显式使用 `formWithExit`。

## 创建与继续维护

`QuickIntakeAttempt` 将创建和更新分成独立逻辑尝试。Own quick intake 不传 sourceId，新建固定版本 1；取得 ID 后，改变资料只对该 ID 使用原版本 PATCH，文件或保存意图变化不能再次 POST /items。每次更新返回的新版本才推进本窗口基线，并发冲突不擅自采用最新版本。创建/更新的未知回执继续原载荷与 key，不能因新输入换号。

图片真实拒绝后允许替换或移除已确认失败文件；未知/上传中队列保留原文件、载荷和 key。已完成文件不在同一窗口重新排队。整体保存仍要等图片完成，原图不删除、不改写。

本片是同窗口修复，不承诺首次创建未知回执跨窗口恢复；该能力按已批准方案另作切片。版本冲突输入留在窗口，带草稿去完整编辑属于下一片。
