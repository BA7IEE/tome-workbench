# 来源成色提示降噪

`conditionRaw` 是来源原文，仅供了解平台描述和后续实物检查。它不能自动映射为本地 `conditionGrade`。待确认卡片、表格和已选批量预检以普通来源信息显示该字段，并提示“本地成色待实物检查”。

新导入候选不再因 `conditionRaw` 存在而写入“来源成色仅作参考，未映射成本地成色”行动警告。旧候选的已保存 `warnings` 与 `IngestCandidateRevision` 保留原样，当前待确认页面从行动警告及“其他系统提示”数量中排除这一句；来源详情与历史存储仍可追溯。品牌未标准化、低置信度或推断建议、来源完整性缺项和疑似重复身份继续醒目显示。

本切片无 migration、无历史批量写入、不改 Agent Skill/Profile，不给 TM 补本地成色，也不触碰采购行、库存、成本、售价、成交或发布。真实成色仍需人工实物检查后按现有商品维护流程记录。
