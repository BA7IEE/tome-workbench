# 1.0.0-rc.15 商品资料库 MVP

日期：2026-09-15。针对已确认的商品资料库需求，将正式持久化业务接到「商品库 / 导入记录 / 设置」。采集、批量平台发布和 AnQiCMS 建站仍由外部工具执行。

本版补齐尺码/位置/来源/缺项找货、明确来源缺项的批量核对、稳定批次成员、离线文件来源证据、原图资料包、人民币表格金额、已售/改价/补图后的变化检查，以及批量和上传丢回执后的关页恢复。已知零成本不再显示为未知。商品页保存后直接整理资料，原发布流程从更多进入，权限和原有业务规则不变。

## 数据与迁移审阅

202609150011_product_materials 仅新增 IngestBatchMember、MaterialExport、MaterialExportEntry，包含 RESTRICT 外键、索引和 append-only 触发器。补入当前可证明的批次成员，不虚构先前覆盖的历史。既有库存、财务、迁移SQL和发布快照未修改；测试清理摘要增加资料包关系依赖。

在用户授权本次修复的范围内逐句审阅新迁移后，用 harness 的 --seal --acknowledge-baseline-change 登记新文件哈希。既有迁移哈希保持原值，没有删除或绕过封存检查。隔离库先运行 prepare-test；本机业务库升级由启动器先离线备份再执行维护迁移。

## 回归依据

- PG 使用 tome_test 和合成数据，增加零/null成本、服务器组合筛选、版本绑定缺项、历史批次、500件分段与幂等、原图文件字节和金额单位、内部财务权限重放、资料变化与清理摘要等测试。

- WebKit 测试暴露恢复队列直接持久化 File 的兼容问题，改为存储原始字节、重建同名同类型文件；不转码、不改请求内容。
- 原导航和主发布按钮测试调整来自已确认的MVP，仍从新入口真实点击执行原发布/销售/资源覆盖。ux2 对应新名称已在 AC_MATRIX 中映射。
- 新断言曾错误要求售出后修改标题必定发生版本冲突；现有库存命令和文案版本独立，修正为允许补标题、禁止普通 PATCH 重新上架。旧并发维护冲突测试保留。

完整命令结果、当前源码指纹和打包状态见 VALIDATION.md 及 docs/validation/1.0.0-rc.15/summary.json。失败记录保留在本机 data/reports；未通过验证的中间状态不作为发行依据。
