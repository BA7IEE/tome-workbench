# 0.8.0-rc.1 · 统一视觉系统

这一版不增加新的业务域，重点解决 0.7 仍然存在的“不同页面像不同系统”的问题。

## 主要变化

- 只保留 `style.css + interaction.css + ui08.css` 三层：基础、可访问性交互、最终视觉系统。
- 停止加载 `usability.css`、`admin-flow.css`、`studio.css`、`ux2.css`，避免多套历史样式互相覆盖。
- 商品库收敛状态标签、页头动作和筛选层级；正式商品不重复显示“正式商品”标签。
- 新建/编辑商品统一字号、间距、卡片、输入框和操作层级。
- 发布工作区在桌面端使用非遮挡侧栏；手机端按页面顺序展示，不覆盖保存、库存等操作。
- 手机商品页明确按名称、图片、归类、价格、成色、描述、尺寸、货源、复核、英文/扩展的业务顺序排列。
- 导航、表格、弹窗、状态标签、运行状态、字典、对账、回收站等后台页面使用同一视觉语言。

## 验证门禁

新增 `test/browser/ui08.spec.cjs`，并纳入 Chromium 与 WebKit：

- 桌面商品编辑器主栏/侧栏比例和横向溢出；
- 手机商品页业务区顺序与卡片宽度；
- 手机端商品、待办、销售、资源、系统五个顶级入口可达；
- 商品列表状态标签克制、页头主动作唯一；
- `main.ts` 只加载唯一最终视觉系统，不允许重新叠加旧视觉层。

原有商品、字典、货源、成交、对账、审计、回收站、故障恢复与数据恢复测试继续执行，不以视觉改版替代业务验证。

## 边界

0.8 仍是内部经营工作台候选，不代表公网生产基础设施、真实第三方自动发布、支付或联网 AI 已完成。没有新增数据库迁移，也没有修改现有业务数据模型。最终结果以 `docs/validation/0.8.0-rc.1/summary.json` 为准。
