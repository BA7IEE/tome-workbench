# 商品库批量菜单内部滚动修复

目标：多选后可以滚动“批量操作”菜单，已选商品保持不变。只涉及商品库菜单事件与样式，不改权限、业务命令、候选决定、TM、库存或数据。

`bindCatalogMenus` 原先在 document 捕获到任何 scroll 时关闭菜单。`.bulk-more > div` 同时设置 `overflow: auto` 与 `max-height: 50vh`（手机 45vh），因此菜单内部滚动也触发关闭。

修复识别 scroll 事件目标是否属于本页面菜单；内部滚动保持打开，页面滚动仍关闭。菜单增加 `overscroll-behavior: contain`，避免到达滚动边缘后把滚动传给页面。未添加 touch/pointer 拦截或 preventDefault；保留原生滚动、外部点击、动作点击、Escape 回焦、resize 和菜单互斥。
