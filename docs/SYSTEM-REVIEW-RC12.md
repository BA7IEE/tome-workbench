# rc.12 继续排查记录

本轮聚焦上轮新增选品操作的边界与异常恢复，并只读检查本机成交页。未对真实商品发起成交、发布、定价或成本写入。

发现并修复：

1. 从商品列表分次加入选品时，只检查本次传入数量，未检查与原草稿合并后总量。现在先按商品ID去重检查40件上限，超限不修改草稿。
2. 合集创建成功但客户端未收到回执后，改名引发本地内容不一致错误会把结果未知标志清除，第二次提交可能使用新命令创建重复合集。现在结果未知标志保持，提供原名称、渠道及商品集合恢复入口，继续原命令键。
3. 渠道随后停用时，页面重建会自动选择另一个渠道，破坏原请求恢复。现在保留用于恢复的原渠道选项，服务端仍禁止新资料包使用停用渠道。
4. README版本与跨页成本功能说明滞后，已更新到当前边界。

测试继续保留原成功恢复用例名称，扩展到连续误重试与渠道停用；新增41件分次加入测试。使用tome_test合成数据，真实写入后截断回执，不用模拟成功响应替代写入。完整回归结果见本版本validation目录，未通过前不宣称发布验证通过。

仍有限制：选品草稿仅在当前浏览器页面会话内保留，不是跨设备或刷新后的持久草稿。本轮不改变此边界，也不声称已完成真实对客发布验收。
