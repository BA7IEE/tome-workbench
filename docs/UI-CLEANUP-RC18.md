# 全系统界面清理 · 1.0.0-rc.18

目标是消除旧样式和旧展示代码对当前 Arco 界面的影响。商品库、导入记录、设置及保留的业务页面使用同一主题，日常按钮应直接执行其名称表达的操作。

## 清理内容

- 删除 style.css、interaction.css、usability.css、admin-flow.css、studio.css、ux2.css。前两份仍在运行的默认值、触摸/键盘、错误恢复、登录及展厅规则已移到 ui08.css；后四份已停用文件从源码移除，历史留在 Git。
- main.ts 只加载 ui08.css；保留 arco-base / workbench / arco / product 的顺序。Arco 变量定义于 body，相应主题别名也在 body 定义，避免继承失效。原生输入与按钮不再干扰 Arco 内部控件；输入焦点不会被旧普通边框盖住。
- 采购、来源、选品等页面的旧变量替换为现有主题，恢复边框、间距和选中状态。删除商品库旧筛选、视图及行菜单布局，保留当前商品库布局作为唯一对应规则。
- 导入和其他业务记录筛选区统一排列与控件高度。手机页头按钮与标题分行，货源筛选框等高；原生记录表格保留可读列宽，内部滚动，不把中文挤成一字一行。商品图片/列表视图明确显示当前选中状态。
- 删除没有调用者的 productFields HTML 生成器及已被 Arco 替代的原生行菜单定位；仍在使用的字段读取、版本处理、批量菜单与页面菜单保留。货源「手工录货」复用快速录货并保留权限限制。
- 更新旧文档和 Harness 文件存在性规则，防止后来按过时说明重新引入旧文件。

## 不变量与验收

后台接口、数据库迁移、库存事务、成本计算、原图字节、发布权利与权限规则没有变更。已有业务控制器继续处理保存、丢回执重试和版本冲突。

最小验收是 Chromium / WebKit 的 1440px 与 390px 逐页主题和操作检查，加上现有商品库排序分页、快速录货、完整编辑、原图、字典、批量导入、成交和恢复用例。旧单例行菜单定位改为目标 TM 的具名菜单，因为同文档 hash 导航返回时，事件可能尚未执行；不改变真实修改和未保存草稿断言。

完整命令、最终结果、失败修复记录和本地应用核对由 [VALIDATION](VALIDATION.md) 记录。全站没有重写为 React，也没有接入自动采集或平台发布。本轮保留非商品页的业务渲染器，统一其样式及实际发现的操作入口。
