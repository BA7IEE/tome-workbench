# rc.19 商品浏览与维护

本轮围绕用户确认的商品资料库 MVP 调整日常交互，保持商品库 / 导入记录 / 设置三个入口。

- 普通商品链接先看详情：大图、关键参数、报价、按权限可见的人民币成本；来源证据与高级复核、素材、财务记录可展开。
- 明确点编辑才出现表单；从详情保存回到同一商品。取消有未保存保护，原批次/列表条件保留。当前页相邻浏览与跨页勾选连续编辑分开。
- 大图可连续翻阅、放大、读取原图及下载原文件。浏览不会改图；已保存图片的变更明确提示立即生效，原件保留。
- 单件录货可以结束，连续录货仍可选；资料生成后自动下载，下载失败重试原包，恢复继续原请求键。
- 完成批次直达本批已归入商品；清筛选保留批次。发布审核标签不再冒充商品资料完整性；批量「检查发布缺项」明确其渠道用途，普通补资料继续走逐件编辑和批量修改属性。
- 暂停用独立确认窗口；复用原库存、询盘和成交控制器，不增加强制财务字段。

无数据库迁移、无依赖升级、无外部采集/自动发布接入。现有库存、账务、版本、字典、媒体权限、原件和丢回执保护保持。

验收入口：docs/validation/1.0.0-rc.19/summary.json 和 verification.log。测试调整与范围见 AC_MATRIX。自动化只使用 tome_test 合成数据，真实本地商品仅做只读界面核对；本地运行不等于公网部署或双方真实经营验收。
