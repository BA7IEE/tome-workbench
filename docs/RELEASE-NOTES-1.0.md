
## 1.0.0-rc.4 · 最终可用性核验

- 经营待办默认只展示“立即 / 优先”事项，普通候选不再淹没行动中心；支持按事项类型和商品搜索。
- 手机经营待办从横向表格改为纵向任务卡片，390px 视口实测无页面横向溢出。
- 待确认商品继续坚持“批量优先”：普通候选每卡只保留“单件处理”，关联已有TM、确认另一件新建、字段调整和来源事实退到二级弹窗。
- 疑似重复商品仍直接突出“核对重复”，不会弱化 rc.3 的实物身份保护。
- 最终人工 UAT 实际走通：快速录货 → 商品维护 → 询盘 → 售出 → 补收支，并复核采购、待确认、经营待办、桌面和手机关键页面。

# 1.0.0-rc.3 · 候选身份防重与归并

- 待确认候选会对来源图片做精确SHA防重，发现已有TM时给出明显提示。
- 同图候选不能再通过批量确认静默生成第二个TM；必须人工核对。
- 经营人员可以输入TM编号/旧别名，把候选的来源、采购订单行和新增来源图片归入已有TM。
- “关联已有TM”绝不改变目标商品的库存、成色、售价和人工维护资料；重复图片不再次塞入商品图库。
- 同款不同件共用来源图时，允许单件明确勾选“确认是另一件实物”后新建，并把覆盖事实写入审计。
- 当前只做确定性强匹配，不把相似图算法当事实；感知哈希/视觉相似与成熟合并拆分工作台仍属后续。

# 1.0.0-rc.2 · 商品经营中台架构重整

## rc.2：经营行动中心
首页「工作总览」与侧边栏「经营待办」现在共用实时行动投影。系统从待确认候选、商品任务、事实冲突、客户询盘和成交收支缺项中生成下一步工作，不复制这些业务事实，也不新增第二套可写任务主表。

优先级按经营风险排序：渠道下架 > 事实冲突 > 成交补账 > 候选确认 > 客户跟进/常规资料任务。同优先级先处理等待更久的事项。只读账户不会看到询盘或成交财务内容；完成操作仍必须进入原业务模块。

## 核心变化
v1.0 把永久 TM 商品提升为唯一日常经营中心。采购订单、物流、RMA、来源平台和外部 Agent 退居来源事实与证据层，不再要求运营人员按订单逐件点击完成入库。

日常一级入口变成：**商品库 → 待确认 → 待办**。历史采购订单保留在「采购历史」用于追溯来源、物流、RMA和成本依据。

## 外部 Agent 接入
Codex、WorkBuddy 或其他桌面 Agent 使用短期单次显示 Token，通过统一 `/api/agent-ingest` 协议提交订单、候选商品和图片。

Agent 只能写采集层；不能创建 TM、改库存、成交、成本、发布或账号。稳定 `externalKey` 使重复采集追加修订而不是制造重复候选。

来源图片持久进入中台并按SHA去重，确认TM后复用原文件，但默认仍是内部参考素材，不自动获得公开使用权。

## 批量确认
待确认页每页真实支持100件，提供图片/表格模式、本页全选、批量生成TM和批量排除。第101件进入下一页，不隐藏截断。

来源资料不完整、品牌尚未标准化都不阻断正常商品生成；来源原文仍完整保留。资料完善与商品可售状态继续解耦。
## 多来源与成本
新 `ItemSourceLink` 允许一件TM关联多个历史来源；升级迁移会把旧 `Item.sourceId` 回填为标准来源关系，旧字段仅保留兼容。

TRR第一阶段成本规则按已确认口径执行：实际经济支付价值（含已使用 Store Credit）按订单原价比例分摊；每单人民币¥200附加成本按最终保留件数平均分摊。实际人民币扣款优先用于推导汇率。

存在RMA、退货或排除商品时，自动成本被阻断，必须人工确认最终经济支付金额。成本确认后一次写入全部TM；销售时冻结当时有效人民币成本，后续重算不反改历史成交。

## 验证边界
v1新增真实PostgreSQL与浏览器测试覆盖：Agent权限隔离、幂等重采集、候选图片、批量生成TM、未知品牌容错、100件分页批量、TRR成本闭合、RMA阻断、售出成本快照及手机待确认页面。

完整release结果必须由 `npm run verify:release` 在当前源码上重新生成。局部测试、旧报告或开发目录截图都不能替代正式发布验证。

## 仍不自动做的事
系统不内置TRR网页机器人，不绑定具体Agent产品；不自动判断图片授权，不把外部 Sold/Shipped 映射成本地库存，不自动猜RMA退款结果，也不自动发布到外部平台。

## 1.0.0-rc.10 操作路径衔接
商品工作区可以直接记录询盘，成功或失败重试均保留尚未保存的商品文案。详情页共享同一询盘表单；工作总览“继续维护”直接进入编辑器。经营待办的“去跟进”定位到指定询盘，不再要求在全部记录中重新寻找；更新后有返回待办入口。
已归入TM的候选停止提供无效批量选择，导入时警告作为可展开历史提示。进入TM维护后，返回/保存并返回恢复原候选筛选。TEST列表返回也保留自身范围内原条件。
旧样式移入legacy层，现有视觉系统统一控制侧栏宽度和弹窗间距。本版保留原库存、权限、财务、图片和幂等规则，无数据库迁移。四个新增浏览器用例及一个数据库用例验证以上路径，完整结果见docs/validation/1.0.0-rc.10/summary.json。
