# 0.11.0-rc.1 · 多来源采购与订单归集

本版新增采购来源层，用于统一记录采购平台、供应商、线下及其他来源。采购记录与商品库存分开：平台状态、平台价格、退货/RMA、物流包裹只保存来源事实，不自动改变本地库存、成色或售价。

采购对象分为来源、订单、订单行、订单金额调整、包裹、退货/RMA。一个订单可以拆成多个包裹；同一订单行保留原货号、原描述、原尺寸、原成色、原状态和原始链接。订单及订单行发生变化时追加不可变修订快照。

订单行金额、平台当前价和平台估计零售价分别保存，不相互覆盖。人民币取得成本必须由经营者按实际人民币支出、确认过的批次汇率或人工分摊结果明确确认；系统不自动换汇，不把订单行金额当成本。
经营流程为：导入采购订单 → 预览核对 → 逐件确认实物是否在手及是否纳入经营 → 生成货源候选或关联已有TM → 必要时确认人民币成本。未完成“纳入经营 + 实物在手”时不能从采购订单行直接生成货源候选。

来源平台的成色词表保持原文，例如 TRR `Excellent` 不自动映射为本地 VC 成色。来源分类仅在明确出现 Clothing / Bags / Shoes / Accessories 一级类别时做保守映射，原始分类同时保留。

采购来源生成的货源候选仍需走普通商品建档。TM商品可关联采购订单行；后续可继续关联其他采购来源。来源图片链接只是内部资料记录，不等于已取得公开使用授权。

本版以TRR调研中的七件订单结构作为合成回归：7个订单行、2个包裹、195/78/400三种价格、折扣/运费/抵用额、RMA/取消/平台Sold均分别验证。真实账户没有被自动采集或批量写入。
