# 1.0.0-rc.8

导入时已采集品牌和成色，但商品库仍提示品牌待补、成色待填，品相细节需进入来源历史寻找。本版保留并直接呈现来源品牌/成色/品相参考，在图片卡片补充成色和尺码，编辑页把来源说明放到对应字段旁。已维护的本地字段始终优先；不自动新增字典或自动认定实物成色。

验证由docs/validation/1.0.0-rc.8/summary.json记录，包含双浏览器新回归与现有全套验证。真实订单资料、维护脚本和验收文件仅存私有data，不进入测试或发布包。

补充多来源架构约定与异构数据集成验收，纠正候选币种缺省固定为人民币的跨来源假设。新候选使用各自来源默认币种，稀疏修订不改变已有币种。映射规则编辑器、自动冲突裁决与任意币种支持仍为待扩展能力。

异构来源验收另发现无订单候选关联已有TM时使用了数据库不接受的关系类型。本版改用现有REFERENCE关系，保持原有数据库约束；门店补充证据可正确关联已有TM。
