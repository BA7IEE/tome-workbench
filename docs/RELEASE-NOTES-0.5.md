# 0.5.0-rc.2 · 统一字典、日常批量操作及测试数据清理

## 本轮实际功能
- 基础数据 → 字典管理：品牌、VC五级成色、颜色、主要材质；支持别名查找、录货中新增、版本校验、适用品类、停用。未知项留空，不猜测成色，不写入重复品牌。
- 新增/编辑商品：标准选项与图片在同页处理；具体瑕疵和成分比例另行保留。商品详情提供明显的图片上传入口。
- 商品列表：品牌、成色、颜色、材质的全库筛选；跨页选择后批量修改指定属性，不勾选的字段保持不变；清空字段必须额外确认；版本冲突逐件提示。
- 操作记录：中文操作、人员和商品编号；支持按人员、商品名称或TM编号搜索。失败任务显示中文状态与处理建议；原始技术信息折叠保留。
- 对账界面：比例直接填写百分数，状态中文显示；更正基础从已确认对账中选择，不要求抄数据库ID。
- 测试数据：新建时管理员可选测试商品。已有模拟成交的商品可从“删除 → 有模拟成交？清理测试数据”或详情“清理测试数据”进入专用预览确认。

## 测试清理不是删除账本
需管理员输入TM号、确认无真实交易/收付款及无真实对外销售，再按最新预览摘要归档。关联商品、成交、退款、成本、原图、审计均保留。正式统计和后续合作对账排除TEST，模拟记录仍可在“成交记录 → 模拟成交”查看。
外部发布观察记录不会改成虚假的“已下架”；只是归档模拟工作并保留声明。涉及已确认对账需额外确认影响，历史快照不变，详情提示生成更正。恢复仍为测试模式和暂停，不会自动转为正式商品。

## 数据与验证边界
新增006字典和007测试范围迁移，不重置业务库。既有商品不会因升级自动归类为测试或被删除。旧字典冲突不静默合并；历史商品/发布快照保持原貌。
所有新增自动化使用tome_test合成数据。单元、数据库集成、两种浏览器、故障注入、全模型恢复及源码包验证以docs/validation/0.5.0-rc.2下的真实报告为准，本文不代替通过报告。
成色采用VC公开平台口径，不宣称通用国际认证标准，也不自动换算The RealReal等级。图片支持JPEG/PNG/WebP；本轮未声称支持视频/任意附件。
公开生产环境、跨主机数据库容灾、真实外部平台接口、支付退款、联网AI和完整跨币种履约未在本轮新增，不能据此宣称整个长期蓝图已经交付。
