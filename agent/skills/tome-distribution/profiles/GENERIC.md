# 通用交易渠道分发 Profile

版本：`GENERIC_TRADE/1.0`。仅适用于 `channel.platform = OTHER` 的标准交付记录。

- 必须原样使用冻结包中的永久 TM、标题、正文、价格、币种和图片顺序；不得自行补商品事实或改价。
- 只有真实取得的稳定远端编号才可作为 `remoteId` 回传；没有稳定编号时留空，并在确认说明中写明按永久 TM 的核对依据。
- 无法确认目标平台是否完成发布、更新或停售时必须回填 `ATTENTION`，不得猜测成功，也不得自动重复执行。
- 本 Profile 不包含平台登录、验证码、Cookie、Token、设备信息、页面步骤、点击坐标、浏览器/APP 自动化或外部重试策略。
